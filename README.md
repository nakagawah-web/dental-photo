# 中川歯科 口腔内写真

スマホで規格写真を撮り、端末に保存し、Google Drive へ同期して、経過を並べて比較するためのアプリ。
ビルド不要の静的Webアプリ。HTML・CSS・JavaScript の3ファイルで動く。

## できること

- 患者の登録（患者番号・氏名・生年月日・メモ）
- 規格写真8枚の撮影（ガイド枠つきで、順番に撮らせる）
- 来院日ごとの保存と、撮り直し
- Google Drive への同期
- 同じアングルの写真を時系列で並べる経過比較

## 規格写真8枚

| # | アングル | ガイド |
|---|---|---|
| 1 | 口腔内 正面 | 中切歯の正中を中央線に、咬合平面を水平に |
| 2 | 口腔内 右側方 | 右の犬歯から第一大臼歯まで |
| 3 | 口腔内 左側方 | 左の犬歯から第一大臼歯まで |
| 4 | 上顎 咬合面 | ミラー使用。正中を中央線に |
| 5 | 下顎 咬合面 | ミラー使用。舌が写らないように |
| 6 | 顔貌 正面（安静） | 唇は閉じずに力を抜いた状態 |
| 7 | 顔貌 正面（スマイル） | 上の前歯が見えるように |
| 8 | 顔貌 側貌 | 右向き。耳と目が同じ高さ |

## データの扱い

口腔内写真は個人情報保護法上の**要配慮個人情報**にあたる。設計は次のようにしている。

- **氏名・生年月日・メモは端末内（IndexedDB）にだけ残り、Drive には送らない**
- **Drive のフォルダ名は患者番号のみ。** 氏名は Drive 側に出ない
- Drive の権限は `drive.file` スコープのみ。このアプリが作ったファイル以外にはアクセスできない
- 写真の実体は端末内にある。**端末を変えたり紛失すると消える。必ず Drive へ同期すること**

### スタッフも使う場合

**Googleアカウントのパスワードを共有しないこと。** 代わりに次の手順にする。

1. Drive にできた `中川歯科_口腔内写真` フォルダを、スタッフ各自のGoogleアカウントに「編集者」で共有する
2. スタッフは自分のGoogleアカウントでアプリにサインインする
3. 退職時は共有を外す

この形なら、誰がいつ操作したかが Drive 側に残り、アカウントを渡さずに済む。

## セットアップ

### 1. 公開する（GitHub Pages）

カメラと Google 認証は HTTPS でないと動かない。GitHub Pages が手軽。

```bash
cd ~/projects/dental-photo
git add -A && git commit -m "初版"
gh repo create dental-photo --private --source=. --push
```

GitHub のリポジトリ画面 → Settings → Pages → Source を `main` / `root` にして保存。
数分で `https://<ユーザー名>.github.io/dental-photo/` が開くようになる。

> プライベートリポジトリの Pages は GitHub の有料プランが要る。無料でやるなら公開リポジトリにするが、**このコードに患者データは含まれない**ので公開しても情報は漏れない。気になるなら Netlify や Cloudflare Pages でも同じことができる。

### 2. Google Drive 連携を設定する

1. [Google Cloud Console](https://console.cloud.google.com/) でプロジェクトを新規作成する
2. 「APIとサービス」→「ライブラリ」→ **Google Drive API** を有効にする
3. 「APIとサービス」→「OAuth同意画面」を設定する
   - ユーザーの種類：**外部**
   - アプリ名・サポートメール・デベロッパー連絡先を入力
   - スコープは追加しなくてよい（`drive.file` は機微なスコープではないため、Googleの審査は不要）
   - 「テストユーザー」に、自分とスタッフのGoogleアドレスを追加する
4. 「認証情報」→「認証情報を作成」→ **OAuth クライアント ID**
   - 種類：**ウェブアプリケーション**
   - 承認済みの JavaScript 生成元に、手順1で公開したURLのオリジンを入れる
     例：`https://<ユーザー名>.github.io`
   - 作成すると `xxxxxxxx.apps.googleusercontent.com` が発行される
5. アプリを開き、右上の歯車 → **OAuth クライアントID** に貼り付けて保存 → サインイン

### 3. ホーム画面に追加する

- iPhone：Safari で開き、共有ボタン →「ホーム画面に追加」
- Android：Chrome で開き、メニュー →「ホーム画面に追加」

アプリとして起動でき、オフラインでも撮影と保存ができる。同期だけはオンラインが要る。

## Drive の保存構造

```
中川歯科_口腔内写真/
  0123/                       ← 患者番号
    2026-09-19/               ← 来院日
      2026-09-19_io_front.jpg
      2026-09-19_io_right.jpg
      ...
```

## 使い方

1. 右下の「＋」で患者を登録する
2. 患者を開いて「この日の撮影を始める」
3. ガイド枠に合わせて撮る →「これでよい」で次へ。うまく撮れなければ「撮り直す」
4. 撮り終わったら「Driveへ同期」
5. 2回目以降の来院を撮ったら「経過を比較」で同じアングルを並べて見る

個別に撮り直したいときは、来院詳細の写真をタップするとそのアングルだけ撮影できる。

## 技術メモ

| | |
|---|---|
| 保存 | IndexedDB（`dental-photo`）。画像は Blob のまま |
| 画像 | 長辺1600pxへ縮小、JPEG品質85% |
| 認証 | Google Identity Services のトークンクライアント（暗黙フロー） |
| スコープ | `https://www.googleapis.com/auth/drive.file` |
| オフライン | Service Worker でアプリ本体のみキャッシュ |
